# 🏥 Quad Solutions

Quad Solutions is a responsive healthcare support website designed for medical service providers. The platform showcases healthcare services such as provider credentialing, insurance enrollment, medical billing, and compliance support through a clean and user-friendly interface.

## ✨ Features

- 🏠 Home page with a professional hero section
- ℹ️ About section introducing the company
- 🩺 Healthcare services overview
- 📞 Contact page with company information
- 📝 Contact form for customer inquiries
- 📱 Responsive design for different screen sizes
- ⚡ JavaScript-based navigation between sections without page reload

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
